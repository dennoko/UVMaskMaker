# MaskMaker 使い方（Unity 2022.3）

このドキュメントは、**MaskMaker** (`Tools > MaskMaker`) の使い方を説明します。Unityエディタ上でメッシュのUVアイランドを視覚的に選択し、マスク画像（PNG）や頂点カラーとして書き出すことができるツールです。

---

## 主な機能
- **UVアイランド選択**: シーンビューまたはプレビュー領域で直接メッシュをクリックして選択。
- **手描きペイント**: プレビュー上でブラシを使って自由にマスクを塗ることができます。アイランド選択と併用して合成出力が可能です。
- **マスク画像の読み込み**: 既存のマスク画像を読み込み、黒い領域を手描きペイント済みエリアとして扱います。以前エクスポートしたマスクを起点として編集を再開できます。
- **自動UV解析**: ターゲット設定時にUVレイアウトを自動解析し、即座に作業を開始できます。
- **Work Copy機能**: メッシュ変形による位置ズレを防ぐため、自動的に作業用の静的コピーを作成して操作できます。
- **柔軟な書き出し**: チャンネル別書き込み（RGBA）、頂点カラーへの焼き込みに対応。
- **インポート設定自動化**: 書き出したテクスチャは自動的に `Read/Write Enabled` と `Streaming Mipmaps` が有効になります。

---

## 基本手順

### STEP 1: 対象モデルの設定
1. メニューから `Tools > MaskMaker` を開く。
2. `Target Model` 枠に対象 GameObject をドラッグ＆ドロップ。
3. **対象マテリアル**（特定のサブメッシュのみ抽出する場合）と**UVチャンネル**（通常はUV0）を選択します。
   - ※ターゲット設定時、UV解析が自動的に実行されます。
   - ※デフォルトでは作業用コピー（`[WorkCopy]`）が作成されます。
4. *（任意）* 既存のマスクを起点にする場合は、`マスク画像の読み込み` カードにマスク画像をセットして **マスクを読み込む** をクリックしてください。詳しくは [1.5. マスク画像の読み込み](#15-マスク画像の読み込み) を参照。

### STEP 2: アイランド選択 ＆ ペイント
1. シーンビューのメッシュ、またはウィンドウ上部の `PREVIEW` 領域をクリックしてアイランドを選択します。
2. **Add** モード（選択追加）と **Remove** モード（解除）を切り替えて操作します。
   - ホットキー（デフォルト `R`）でモードを素早く切り替え可能です。
3. `Invert`（反転）、`Select All`（全選択）、`Clear`（全解除）ボタンで一括操作も可能です。
4. **ペイントモード**: プレビュー直下のツールバーで「ペイント」を選択すると、各種ツールを使って直接マスクを塗ることができます。
   - **ツール種類**:
     - **Brush (ブラシ)**: 左クリック＋ドラッグで自由な線を引きます。
     - **Rect (矩形)**: ドラッグした四角形の範囲を塗りつぶします。
     - **Lasso (投げ縄)**: 囲んだ範囲を塗りつぶします。
     - **Eraser (消しゴム)**: ブラシと同様の操作で塗った部分を消去します（アイランド選択は消えません）。
   - **ブラシサイズ**: Brush/Eraserツールの太さを調整します（1〜100px）。
   - **戻す / やり直す / クリア**: 塗りの履歴操作や全消去が可能です。

### STEP 3: エクスポート
1. `Quick Export` セクションで解像度、マスク反転の有無、ピクセルマージンを確認します。
2. `PNGを保存` をクリックしてマスク画像を書き出します。

## 各セクションの詳細

### 1. Target Model（対象モデル）
- **Object**: 対象となる MeshRenderer または SkinnedMeshRenderer を含む GameObject。
- **対象マテリアル**: 特定のサブメッシュのみを解析対象にします。UVが重なっているモデルで特定の部位のみ抽出したい場合に有効です。
- **UVチャンネル**: 解析に使用するUV（UV0〜UV7）を指定します。
- **ワークコピーを作成 / コピーを削除して戻る**:
  - メッシュ変形（Modular Avatar等）の影響を受けない作業用の複製を作成します。
  - 作業後に「削除して戻る」を押すと、元のオブジェクトを対象とした状態に復元されます。

### 1.5. マスク画像の読み込み
既存のマスク画像を読み込み、黒いピクセルを手描きペイント済みエリアとして扱います。
スクラッチから始めるのではなく、以前エクスポートしたマスクPNGを起点として編集を再開することができます。

- **画像フィールド**: Projectウィンドウから `Texture2D` アセットをオブジェクトフィールドにドラッグ＆ドロップするか、ピッカーから選択します。
- **黒の閾値（0〜255）**: この値より輝度が低いピクセルを「手塗り済み」として扱います。デフォルトは `128`。
  - **低い値**（例: 32）: ごく暗いピクセルのみを取り込みます。マスクに薄いグレーのにじみがある場合に有効です。
  - **高い値**（例: 200）: やや暗いグレーのピクセルも取り込みます。アンチエイリアスや半透明の境界を含めたい場合に有効です。
- **「マスクを読み込む」ボタン**: 画像の黒い領域を現在の手描きレイヤーに適用します。
  - 取り込みは既存のペイントデータと**OR合成**（上書きではなく追加）されます。
  - この操作はプレビューツールバーの `戻す` でUndo可能です。

> **Tips**: 読み込み後にペイントモードへ切り替えると、ブラシや消しゴムで細かい調整が行えます。

### 2. アイランド選択
- **Add / Remove**: クリック時の基本動作を切り替えます。
- **選択数表示**: 現在選択されているアイランドの数を確認できます。
- **一括操作ボタン**:
  - **Invert**: 未選択の島を選択し、選択済みを解除。
  - **Select All**: 全ての島を選択。
  - **Clear**: 全ての選択を解除。

### 3. PREVIEW（プレビュー）
- 解析されたUVが表示されます。
- **ビュー操作**: マウスホイールでズーム、右ドラッグでパン（移動）が可能です。
- **size reset**: 表示を初期位置に戻します。
- 直接クリックしてアイランドを 選択/解除 することも可能です。

#### 手描きペイントの詳細
アイランド単位の選択だけでなく、ピクセル単位での自由な描画が可能です。

- **操作の切り替え**: プレビュー下部のツールバーで「ペイント」を選択すると描画モードになります（「選択」モードに戻すとアイランド選択操作になります）。
- **描画ツール (Toolbar)**: 
  - **Brush**: 自由な線を引きます。
  - **Rect**: 四角形の範囲で塗りつぶします。
  - **Lasso**: 任意の形を囲んで塗りつぶします。
  - **Eraser**: 塗った箇所を消去します。
- **Undo / Redo**: 
  - 描画中のストロークは個別に `Undo` (戻す) / `Redo` (やり直し) が可能です。
  - ※アイランド選択の解除とは別の履歴として管理されます。
- **アイランド選択との合成**: 
  - 最終的なマスクは **[アイランド選択された領域] ＋ [手描きペイントされた領域]** の合計値（OR演算）として出力されます。
  - つまり、アイランド選択されている場所を消しゴムでなぞっても、アイランド選択自体を解除しない限りは出力に含まれます。

> **Tips**: アイランド選択で大まかに形を取り、細かい部分を手描きで微調整するのが効率的です。

### 4. Quick Export（クイックエクスポート）
- **解像度**: 出力画像のサイズ。
- **マスク反転**: 黒（不透明）と白（透明）を最終的に入れ替えます。
- **ピクセルマージン**: UVシーム付近の滲みを防ぐため、黒領域を数ピクセル膨張させます。

### 5. 出力設定（詳細）
- **File Name**: 出力ファイル名（拡張子なし）。
- **Output Folder**: 保存先フォルダ。フォルダや画像を枠内にドロップして指定も可能です。
- **メインテクスチャのフォルダを使用**: チェックを入れると、モデルのテクスチャと同じ場所に保存します。
- **反転マスクも同時に保存**: 通常のマスクに加えて `_inv.png` を同時出力します。

## 詳細オプション（Advanced Options）

### Scene Overlay（シーンオーバーレイ）
シーンビューでの表示設定です。
- **最前面に描画 (X-Ray)**: 常に手前にワイヤー/シームを表示します。
- **太さ / デプスオフセット**: 線の太さや、面との重なり（チラつき）を調整します。
- **色設定**: 選択中の色やシーム線の色を自由にカスタマイズ可能です。

### Channel Write（チャンネル別書き込み）
特定のRGB(A)チャンネルにのみマスクを書き込みます。
- **有効**: チェックを入れるとチャンネル指定が有効になります。
- **ベースPNG**: 上書き対象の画像をセットします。

### Vertex Color Bake（頂点カラー焼き込み）
選択マスクを頂点カラーとしてメッシュに書き込み、新規アセットとして保存します。

### 環境設定（Preferences）
ツール全体の設定です。
- **言語切り替え**: UIを英語/日本語で切り替えます。
- **トグルホットキー**: モード切替に使用するキー（初期値 `R`）を変更します。
- **ワークコピー自動生成**: ターゲット設定時に自動でWorkCopyを作るかどうか。

## トラブルシューティング

**Q. メッシュをクリックしても反応しない**
- 対象オブジェクト（またはWorkCopy）が正しく設定されているか確認してください。
- メッシュの「表面」をクリックしているか確認してください（裏面は判定されません）。

**Q. マスク画像の境界で白く滲む**
- `Pixel Margin` の値を調整してください（推奨: 2px〜）。黒領域をわずかに拡張してUVの隙間を埋めます。
